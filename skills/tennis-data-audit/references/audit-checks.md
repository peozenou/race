# Scoped module audit checks

Read only relevant sections. These are checks to perform, not assertions that data, destinations or capabilities exist. Current explicit instructions and v2 shared contracts control Race; historical seven-step artifacts remain immutable evidence.

## Acquisition and external equality

Verify raw SHA-256, identity/URL, schema, actual publication/capture/event dates and exact-run checkpoints. Canonical joins need unique source IDs/aliases, stable keys and revisions for corrected observations. Inspect all mapped fields and separately count checked, excluded, missing and unexamined scope.

TA requires complete selected-roster coverage, paired All Results Serve/Return views, grounded filters/URL/table structure and evidenced empty seasons. Compare typed B:X values, original blanks, order and complete row sets. Hidden data never fills visible blanks. Breakpoint fractions remain text, percentages numeric fractions and duration units follow the workbook. Retain completed retirements/walkovers with blank statistics; withhold unfinished/postcutoff records and reconcile completion independently of event-start dates.

Elo requires both entire published reports, with separate schemas/dates, year-month text, blanks/types/order and missing/extra/duplicate checks. Preserve full dated history. TE requires actual pagination/table selectors, publication and uniquely resolved Race/ATP rank/points joins including required tails. Missing is not zero. Temporal differences between a midweek LIVE table and frozen publication need reconciliation, not automatic error classification.

The installed audit_display.py helper may compare capture ZIPs with native Sheet cells beginning at A1. Inspect its actual season/interface limits first. It is not a certificate for cutoff, Elo, TE, history/style preservation or other seasons.

## Internal workbook and release preservation

Inspect native metadata, bounds, entered/effective formulas, formats/notes/protection and exact verified backups. Compare changed and protected scopes; preserve IDs, unrelated cells and old/frozen data. Verify legitimate row/column/table insertion effects and effective calculations, not formula presence alone.

Use current approved roster/scoring/transfer versions. Independently replay +5 qualifying credits, contest identities, actual eligible dates and incoming/outgoing guards. Two player perspectives must not duplicate a contest bonus. Preserve historical membership/earned credit and explicit adjustments; do not infer rules from old notes or silently change a date convention.

Reconcile all five Race/Duels/adjustment/Total paths across frozen source, JOUEURS, HEBDO, BILAN and resolved TEAMS blocks. Adjustments already inside Race are not added twice. Inspect exact-once weekly extension, native table/sparkline ranges, duplicate/skipped dates and stale fallbacks. Derive actual row/column mapping from headers. Transfers or source revisions may reduce totals; monotonicity is not universal.

Before sealing, prove protected baseline plus precise routine deltas; establish a full baseline initially/after structural or historical changes, and fall back to full checks if coverage is insufficient. After sealing, compare the immutable release dependencies/hashes. Unrelated LIVE import health remains separate. Real frozen-data/rule/output changes create linked revisions and affected approval; never silently rebind.

## Private observations and match records

UTR audit compares Patrick's supplied value/date-or-week/type and provenance, without inventing a measurement timestamp or missing week. Resolve actual private destination/duplicate keys. MatchTrack audit preserves original bytes/order; distinguishes same-day rematches, logical duplicates and corrected exports; verifies point progression under actually known format and reconciles final score/completion/partial coverage. Missing server/format/rally/error context remains unknown, qualified or blocks its dependent output.

Rates use observed count/opportunity denominators. Distinguish game and point share, serve-in and serve-win, and point-weighted versus descriptive match means. Preserve opponent/surface/format/sample context as known then. A logged zero is not automatically an observed event or a valid rally length. Keep approved overlays separate from original raw records; failed/qualified records are never silently promoted.

## Analytical methods and optional figures

Check intended use, population/grain, definitions, availability timing, future-data leakage, preprocessing scope, out-of-time evaluation, baseline, calibration/error/uncertainty and sample/selection/censoring limitations. Do not certify unsupported personal career probabilities or treat elite associations as causal junior targets.

If a separately requested PWOL audit applies, state winner-higher/eligible paired denominator with ties/missingness; a separately labeled lower-is-better transformation does not make 100 minus PWOL equal loser-higher when ties exist.

For a separately requested figure, bind plotted values, endpoints, labels/colors and cutoff to the exact reviewed source; distinguish rendered artifact, delivered file and any manual insertion confirmation. A routine Race run requires no PNG or email work.

## Evidence report

Each record includes check ID/purpose, run/release/module, season/week/cutoff, source/destination references and digests, mapping/version, expected/observed counts, field/row denominator, discrepancies, scoped verdict, consequence and next action. Summary lists examined modules, exact coverage, withheld outputs, bounded exceptions, unresolved checks, totals only when actually recomputed, backup/repair scope and remaining gates. Private junior details stay outside public pro artifacts. Audit creation, live access, executed checks, repair authorization, verified write and release approval are distinct evidence events.
