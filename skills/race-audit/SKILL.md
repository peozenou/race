# Race v2 audit and release review

Read the [shared contract](../update-the-race/references/run-contract.md). Independently check primary evidence against the frozen reviewed Sheet/export-value scope; equality to an approved payload alone is not a source audit. Verify all active players and eligible mapped TA fields/types/order, selected TE joins/tails, cutoff, native formulas/tables, all five totals, +5 scoring, transfers and protected history. Missing or unexamined required scope cannot pass.

Cache checked results by full dependency digests. Reuse unchanged source/parser/roster/rule/cutoff/protection checks, not unsupported success booleans. Routine in-profile recovery does not need another approval; out-of-profile repairs return to the owner with a concrete diff and user decision.

Seal the release snapshot and six candidate hashes. Present one concise review with actual source dates, counts/changes, five totals/deltas, backup references, exact public diff and bounded exceptions. Ask Patrick to approve this exact candidate hash for phase 3. This is the second routine decision; no later per-module release approval is added.

Record genuine human approval bound to that hash. A later LIVE-only import failure is separate health information and cannot revoke the sealed release. A changed frozen dependency or candidate payload creates a linked revision and renews only affected review. No email action follows this audit.
