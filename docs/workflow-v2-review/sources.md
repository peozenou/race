# Official sources and capability boundaries

Checked 9 November 2026. Product capabilities and prices may change; recheck during implementation.

- [Codex scheduled tasks](https://learn.chatgpt.com/docs/automations?surface=app): scheduled local work needs the computer and app available; chat schedules and standalone project tasks are different routes. Test unattended permissions and source access. This does not establish this account's iPhone delivery.
- [Codex on mobile](https://learn.chatgpt.com/docs/mobile): supported mobile/remote access is a possible owner entry point, subject to account availability and notification testing.
- [WebKit: iOS/iPadOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/): iOS/iPadOS 16.4+ Home Screen web apps, user gesture/permission, no Apple Developer Program membership required for this route.
- [Apple: sending Web Push](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers): implementation guidance; a service worker and actual sending service are still needed.
- [Apple account overview](https://developer.apple.com/help/account/basics/about-your-developer-account): free Personal Team development has seven-day provisioning and device/app limits; unsuitable as a maintenance-free distribution plan for friends.
- [Apple Developer Program](https://developer.apple.com/programs/): ordinary distribution membership listed at USD99 per year. No enrollment is requested by this proposal.
- [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages): public static hosting on GitHub Free; not a private approval backend or secret store.
- [Quarto Revealjs](https://quarto.org/docs/presentations/revealjs/): editable Quarto presentation source.
- [Quarto presentation delivery](https://quarto.org/docs/presentations/revealjs/presenting.html): browser presentation and printing. The PDF in this review is the print rendering of the Quarto HTML slides.

Architecture choices, phase weights, checkpoint times, projected efficiency and the PWA roadmap are proposals, not provider guarantees. No source establishes a permanently free GPT/Claude execution or always-on backend. No notification was sent and no iPhone delivery was tested while preparing this package.
