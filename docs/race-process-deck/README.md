# Process deck

The whole weekly update process in 26 slides: overview and principles; the data acquisition, analytics and dashboard production layers with their four gates; API construction; and the end-user experience.

- [process.html](process.html): self-contained reveal.js deck
- [process.pdf](process.pdf): printed from the HTML deck
- [process.qmd](process.qmd) and [theme.scss](theme.scss): source

To rebuild with Quarto 1.6 or later, run `quarto render process.qmd`. For the PDF, open `process.html?print-pdf` in Chrome and print it at 1280 × 720 px with background graphics turned on.
